# SlipFlow

一个**纯本地、无联网、无登录**的 Excel 票据核对工具。把发票 / 入库 / 凭证 Excel 拖进浏览器,自动识别列、归一单位、交叉核对。

> 在线访问:https://rectanilrecardo.github.io/slipflow/

---

## 它解决什么问题

财务 / 运营经常需要把三类表对齐:

- **发票表**(增值税发票:供应商、日期、金额)
- **入库 / 出库表**(供应商、日期、数量、单位)
- **记账凭证**(凭证号、日期、摘要、金额)

人工对账容易出错的几个点:
- 列名千变万化(「金额」「价税合计」「含税金额」「合计」全是金额)
- 单位混乱:重量有「吨 / 公斤 / 千克 / 克 / 磅」,金额有「元 / 千元 / 万元 / 亿元」
- 单位不一致直接相加 → 数字错得离谱

SlipFlow 自动识别列角色 + 单位归一 + 交叉核对,核对差额超过 ±¥0.01 或 ±0.01t 就报警。

## 隐私声明

**所有文件处理 100% 在你浏览器本地完成,文件从不上传到任何服务器。** 打开 DevTools → Network,你会看到上传文件后零网络请求。代码完全开源,可自行审计。

页面用到的 SheetJS / pdf.js / Tesseract.js 都打包在 `vendor/` 下,首次加载后即可离线使用。

## 单位归一引擎

### 重量(基准:吨)

| 输入 | 倍率 |
|---|---|
| 吨 / t / mt | 1 |
| 公斤 / 千克 / kg | ÷1000 |
| 克 / g | ÷1,000,000 |
| 磅 / lb | ×0.45359237 / 1000 |

### 金额(基准:元)

| 输入 | 倍率 |
|---|---|
| 元 / CNY / RMB | 1 |
| 千元 | ×1,000 |
| 万元 | ×10,000 |
| 千万 | ×10,000,000 |
| 亿元 | ×100,000,000 |

### 单位识别优先级

1. 列表头直接匹配(例:`发票金额(万元)`)
2. 列内单元格的单位标记
3. 中文财务上下文兜底(`发票/价税/含税/凭证/记账/借方/贷方/合计/金额` → 默认元)

发票列与凭证列单位不一致时,自动归一到「元」再核对,UI 顶部显示双单位提示条。完全无法判定的不可比单位,会拒绝核对并给出黄色警告。

## 使用方法

1. 打开 https://rectanilrecardo.github.io/slipflow/
2. 切到「Excel 核对」标签页
3. 拖入(或选择)Excel 文件 — 支持 `.xlsx` / `.xls` / `.csv`,可一次拖多个
4. 自动识别后,看顶部统计卡片:
   - 发票合计金额(自动汇总徽章 + 单位归一 chip)
   - 入库合计吨数
   - 凭证合计金额
   - 核对结果:差额、差异率、是否通过 ±0.01 阈值
5. 不放心可以滚到下方明细表,直接在网页上 contenteditable 修订单元格,数据实时回算

也可以点「加载示例」用内置远大文件试用。

## 技术栈

- 纯静态 HTML / CSS / 原生 JavaScript,无构建步骤
- [SheetJS](https://sheetjs.com/) 解析 Excel
- [pdf.js](https://mozilla.github.io/pdf.js/) 解析 PDF 票据
- [Tesseract.js](https://tesseract.projectnaptha.com/) 离线 OCR(中文简体 + 英文)
- 体积约 50 MB(几乎全部是 OCR 语言包)
